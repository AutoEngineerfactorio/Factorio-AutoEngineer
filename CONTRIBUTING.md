# Contributing to Factorio AutoEngineer

Thank you for helping build a trustworthy Factorio AI companion.

- Open an issue describing a bug, proposal, or compatibility problem before large changes.
- Test only on disposable or backed-up Factorio worlds. Never submit personal saves, RCON passwords, or API tokens.
- Prefer narrowly scoped, auditable gameplay actions with clear preconditions and postconditions.
- Do not add raw Lua/RCON execution to the AI's direct tool surface.
- Preserve user control: approvals, stopping, and manual takeovers must remain reliable.
- For third-party libraries, mods, assets, and code, include license and attribution details.
- Please include reproducible steps and environment details with bug reports, but remove usernames, paths, and credentials.

Original project contributions use the [MIT License](LICENSE). Preserve third-party license and attribution notices. A contributor code-of-conduct may be added as the project matures.
