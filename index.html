From proof of concept to AI teammate

🧠 Local intelligence

Plans through a local language model. A supervised Python controller mediates gameplay actions.

🎮 Play together

Approve individual actions today; optional in-game control and task handoff are planned.

🖥 Visual control

A basic Windows approval dashboard is working. Maps, inventory, and live objectives are on the roadmap.

Development status

We have demonstrated local AI-generated movement in a Factorio test world, with player approvals and post-action verification. Autonomous factory construction, robust security controls, the in-game companion panel, and mod support are still under development.

There is no public stable release or installer yet. Follow the repository for progress or contribute through GitHub issues.
