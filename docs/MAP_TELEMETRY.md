# Read-only map overlays

The industrial dashboard and launcher use original UI styling. Installed Factorio item icons are read locally at runtime and are not bundled. The map has pan, wheel/button zoom, follow player, cursor coordinates, a chunk grid, player name and layer toggles. Inventory retains real main-inventory slot positions, stack counts and quality markers.

The no-argument autoengineer_view tool adds optional bounded overlay schema 1 while retaining dispatch policy 7 and the existing twelve-tool allowlist. Pollution reads charted chunks intersecting the 256 by 256 character-centered window (at most 81 cells); each cell carries clipped width/height. Electric supply areas and existing copper connections include up to 128 visible own-force poles with at most 16 visible endpoints each. Logistics/construction squares include up to 64 visible roboports and active status. Up to 128 visible own-force turrets show prototype nominal range, not a claim about ammunition, power, effective combat readiness or research-adjusted artillery range. Up to 128 station names and 128 charted force tags are displayed. Player name is limited to 128 characters. Per-layer errors disable only that layer; bounds/truncation are explicit. Empty Lua tables are supported.

Nothing charts terrain, generates chunks, creates connectors, selects entities, changes force tags or issues gameplay commands. Only current surface/local chart data is included. This is not full remote-view parity: distant browsing, surface switching, search, tag editing and remote building/train commands are not implemented. Terrain outside the bounded snapshot remains black. Dynamic entities require currently visible chunks. Pollution and tags use charted chunks, like the force map. The observer continues while the AI is stopped and reports stale/unavailable data on connection loss.

Both backend and child-process display boundaries validate collections, finite values, text, positions, widths, flags and connector endpoints. Unsupported layers stay disabled. The live test used Factorio 2.0.77, normal speed and the reusable isolated test save. Temporary poles, roboport, turret, station and tag fixtures produced nonempty overlays; electrical connections, positive coverage/range and parser roundtrip passed. Fixtures were removed and original sampled pollution restored. This does not certify arbitrary modded prototypes or every Space Age surface. Space Age remains vanilla; modded support is last.
