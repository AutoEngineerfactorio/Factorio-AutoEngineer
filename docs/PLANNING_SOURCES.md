# Planning research sources

All URLs below were collected from the 24-file planning archive. Checked entries were opened on 2026-10-18; remaining entries are retained research leads, not verified compatibility claims. A source reference does not imply permission to copy code/designs, install dependencies, download weights or alter game profiles. Check exact versions, license and runtime behavior when implementing each requirement. Historical blog designs are not a substitute for installed-game data.

## How sources guide implementation

Use Wube API/versioned documentation and runtime prototypes for mechanics; author repositories and mod metadata for integrations; Helmod/FactorioLab for production-workflow comparisons; Draftsman for evaluating blueprint tooling; FLE for reproducible evaluation ideas; Brian's designs for expansion coordination concepts. Independently calculate rates and geometry and validate actual outcomes. Community blueprint sites supply user-authorized imports with provenance, never default redistribution rights.

The current [LuaItemStack documentation](https://lua-api.factorio.com/latest/classes/LuaItemStack.html) is version 2.1.22. It documents blueprint import/export/build APIs; that does not establish the tested 2.0.77 interface. [Draftsman's documentation](https://factorio-draftsman.readthedocs.io/en/latest/) describes blueprint manipulation and data-lifecycle support; dependency adoption still requires a separate compatibility/license decision. [Wube's train design](https://www.factorio.com/blog/post/fff-395), [platform overview](https://www.factorio.com/blog/post/fff-381) and [quality design](https://www.factorio.com/blog/post/fff-375) provide domain context for R11/R15/R16; installed profiles determine supported behavior.
